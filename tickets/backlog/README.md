# Backlog

**Noch nicht fertig.** Hier liegen Aufträge, die es geben soll, die aber noch nicht bereit sind: Ziel oder
Akzeptanzkriterien können sich noch ändern, Abhängigkeiten sind noch offen, niemand hat sie zum Bauen
freigegeben.

- Aus dem Backlog wird nichts gezogen und nichts begonnen.
- Ein Auftrag verlässt das Backlog, wenn er fertig beschrieben ist und seine Vorgänger erledigt sind.
  Dann wandert er nach `selected-for-development/`.
