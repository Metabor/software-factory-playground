# Selected for Development

**Fertig zum Entwickeln: kann begonnen werden.** Hier liegen Aufträge, die vollständig beschrieben und
zum Bauen freigegeben sind.

- Von hier wird gezogen. Wer einen Auftrag beginnt, verschiebt ihn nach `in-progress/`.
- Steht in einem Auftrag „Blockiert durch", wird er erst begonnen, wenn die genannten Aufträge in
  `done/` liegen.
